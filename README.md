# Minicurso Git & GitHub — Conflitos de Merge

Repositório utilizado na segunda atividade prática
da Aula 2 do minicurso da DataLab.

## Objetivo

Aprender a identificar e resolver conflitos
de Merge utilizando branches locais.

## Importante

Toda a atividade será realizada localmente.

Não é necessário executar git push nem abrir
Pull Requests neste exercício.
